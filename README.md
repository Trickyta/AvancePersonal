# Sistema de Monitoreo Agroexportadora

Proyecto de monitoreo remoto de temperatura y humedad para almacenes de frutas.

## Tecnologías utilizadas

- Python
- Flask
- SQLite
- HTML
- Chart.js

## Funcionalidades

- Simulación de sensores ESP32
- Monitoreo de temperatura
- Monitoreo de humedad
- Alertas automáticas
- Dashboard web
- Historial de registros
